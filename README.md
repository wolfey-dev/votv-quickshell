### VoTV Quickshell 
A simple Quickshell based on the computer in VoTV (Voices of The Void).

I made this mainly to learn a little bit about quickshell and qml, it's definitely not optimized and not meant for daily use.

https://github.com/user-attachments/assets/0263e8b8-ebf6-4a1b-97b6-f85a8b01b0a1

### Installation
`git clone` and run `qs -p shell.qml`

### Dependencies
- `quickshell-git` 
- `qt6-base`
- `qmltermwidget`
- `ttf-fixedsys-excelsior-linux `
